# Cats vs Dogs artwork

Original artwork created for Inner Circle with OpenAI image generation, October 2026. No third-party character or brand references.

- cat.webp: transparent circular glossy coral-orange token, cute orange tabby, green eyes, contained face and ears, generous clear edge.
- dog.webp: matching transparent circular cobalt-blue token, cute golden retriever puppy, happy tongue, contained face and ears.
- catalog.webp: cat and dog portraits above a blue four-in-a-row board, dark navy square composition legible as a small game thumbnail.

Version 2.2.15 resizes the bundled art to 384px for its actual display size, using lossless WebP encoding at that resolution. Runtime decodes each once off the UI thread. Gameplay retains the exact seven-column, six-row board and existing rules/AI. The catalog is illustrative.
