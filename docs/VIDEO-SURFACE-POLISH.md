# Video Edit surface polish

Refinement based on the supplied 0.100.29 phone screenshots: the loose three-column icon grid, large unstructured tool area, competing accent labels and heavy selection outline weakened visual hierarchy.

- Two-column tool cards share consistent padding, rounded themed surfaces, subtle boundaries and concise descriptions. A visible scroll indicator identifies additional tools when portrait previews or large text leave less space. Sparse tabs use the same structure; Audio includes Add audio, opening the existing signed OnKlav Files picker.
- Each tool surface has a compact heading and always-visible Add clips action. The bottom category dock has a subtle divider, tighter spacing and selected-state semantics.
- Preview, playback, timeline and settings remain stable when opening tools. The selected-item label sits inside a separate timeline surface with a lighter clip selection border; descriptive text uses neutral foregrounds so active controls retain emphasis.
- Export is a labeled compact header button. Playback no longer competes with a second oversized circular control.
- Existing staged edits, confirmation, save feedback, Undo/Redo, keyboard behavior and media engine are preserved.

Verification and rendering results are recorded in video-surface-verification.json. No APK requested for this refinement; 0.100.29 predates it. Physical-phone acceptance remains pending.
