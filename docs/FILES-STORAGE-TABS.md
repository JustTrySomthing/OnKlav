# Files storage tabs

Replaces the OnKlav System Files and Android Files folder cards with OnKlav / Android tabs immediately below search. The active tab uses the theme primary container; the other uses its neutral surface. Both roots show Audio, Video, Images, Documents, Downloads and Trash. Existing user-created OnKlav folders remain accessible alongside these roots.

Android Images includes DCIM camera photos. The Android tab has an Internal files link at the bottom for browsing the shared-storage directory tree, including APK and other files. Android private app directories remain subject to Android access restrictions.

Home returns to the active storage root. Header icons use balanced sizes with matching touch targets. Grid pencils overlay the upper-right image corner using the same theme surface, primary icon and rounded-square treatment as gallery stars; filenames use the full caption width. List-view pencils remain beside their rows.

Android Delete now moves files/folders into a recoverable OnKlav-managed Android Trash. Restore preserves originals and refuses to overwrite an existing destination. Delete Permanently remains explicit. This is the trash managed by OnKlav, not a combined view of Samsung/Google apps' private trash stores.

No APK requested for this increment; 0.100.40 predates these changes. Source compilation and focused test results are recorded in files-storage-tabs-verification.json.
