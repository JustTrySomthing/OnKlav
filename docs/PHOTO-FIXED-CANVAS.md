# Fixed crop canvas and image geometry

Crop now defines an axis-aligned window in the oriented source canvas. The image transform maps the full source around its center, then output clips to the selected window; no expanded/rotated canvas. Geometry, preview and export share that mapping. Colors/effects grade the final cropped pixels; Crop context composites the exact selected export pixels over fully edited surroundings.

Geometry uses precision sliders, original-position markers,0.1-degree/1-percent nudges, image Fit/Fill and an independent Reset geometry. View zoom never changes edit parameters. Original is a labeled toggle, preserving the canvas dimensions. Save is the rightmost header icon. Save copy uses OnKlav Files, JPEG/PNG and correct transparent/white edges; success waits for internal filing. Save changes requires a writable selected JPEG/PNG and detects source conflicts. Existing signed Files import/trash/rename actions replace internal files with recoverable prior versions, explicit source provenance, root-capability checks and an interrupted-replacement journal. No direct content index/blob mutations or native/SDK Wasm change. External providers retain a verified prior-image copy in the editor; read-only/unsupported formats use Save copy.

32 focused host/UI checks pass, including Undo/Redo, defaults/reset, view/source reload ordering, rendered output, original-source preservation, internal replacement recovery, provider rollback and interrupted Open source/target binding. Final packaging verification is recorded in photo-fixed-canvas-verification.json. Actual provider/phone memory/touch acceptance remains separate.

Internal save-back creates a new Files-owned content ID at the same active filename/folder and archives the prior ID in Trash. The current opaque selection URI is retargeted; other consumers holding the prior content ID retain the previous version. External overwrite keeps a recovery copy; rollback requires continuing authorization.
