# Crop preview consistency and Audio Editor name

Audio is renamed Audio Editor in its signed version4 manifest, Wasm screen title and host help/permission text. The original app ID app.onklav.audioeditor, publisher, capabilities and private draft paths remain unchanged. Only the Audio SDK app is rebuilt; all other packages are reused.

The old Crop tab directly painted the unedited original bitmap. It now paints color/effect-processed source context under the same crop-relative geometry matrix as export. The selected source patch uses the exact crop-dependent grading, vignette, HDR and sharpening result used by export; surrounding image remains visible under the dark mask so the crop can be expanded. The saved export pipeline/order and crop parameters remain compatible.

The crop outline, thirds grid and eight handles are projected through rotation, flips, independent scale and perspective. Pointer positions are mapped back through the inverse matrix before changing the source crop. A drag freezes its view mapping so it does not chase a refitting image; release updates the fit and commits one undo step. Other edits are preserved. A projective horizon outside a very small selection is excluded from the fit calculation to keep the selected area visible and finite; the Full image ratio action can always restore all source context. No additional image tools or permission changes.
