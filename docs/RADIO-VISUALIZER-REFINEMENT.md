# Radio visualizer refinement

The visualization stage occupies the actual space between controls in both orientations; immersive landscape fills the entire display after controls hide. Wave uses a rising-zero-crossing-anchored 144-sample portrait window versus 512 landscape, gentle smoothing and bounded display gain. Spectrum baseline is near the stage bottom with a short fading reflection. Orbit uses the smaller stage dimension for radius and reach with square-root display response for quiet spectra; silence remains zero.

The compact effect button opens a scrollable snapping wheel with direct row selection and a Use action. One colored-circle button opens six named accessible swatches: red/yellow/blue/orange/green/violet. Mode and color are remembered. Seven original Canvas scenes: Wave, Spectrum, Orbit, Mandala, Slipstream, Aurora, Prism Bloom. Prism Bloom combines layered translucent crystalline petals and a sound-reactive glowing heart. Reactive scene phase advances only with captured sound; pause/background/empty samples clear energy. Existing positive-session capture, <=30Hz/1024samples/32FFT bands, permission checks and rotation restoration retained. No mic/global mix/cloud/dependency additions or copied Velo source/assets. Velo is the visual inspiration, not a port or equivalent shader/performance implementation.

Live station completion now reconnects at the live edge instead of ending its queue. Transient IO/timeouts/server loss use the same bounded recovery. Three rapid attempts use 250/1000/2500ms delays, then show a clear error with manual retry. At least 15 seconds of playback restores the reconnect budget. Same station authorization is rechecked during prepare. Explicit Pause/Stop, replacement, sleep deadlines and revoked permission suppress pending reconnections. Podcasts/audiobooks and finite media keep existing end-of-queue behavior. No fake continuity of audio during server reconnection.
