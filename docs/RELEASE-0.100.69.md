# OnKlav 0.100.69-rc1

ARM64 debug APK, version code 178, using the existing update signer. The shared built-in games export and the Android Rust core were rebuilt from the current source. The signed app packages and Shroom cartridge were verified against their corresponding source artifacts.

Includes live round scoring in Neon Dominos, Air Hockey rail and goal lighting, the current Blackjack, Cats vs Dogs and Crash Test Panda updates, Shroom 0.2.0, and the native Browser download-routing fix. The remaining bundled games and app packages were included in the build.

Build evidence lives in `docs/evidence/v0.100.69` and `docs/evidence/game-sdk`. Physical handset and carrier tests are separate from the build checks.
