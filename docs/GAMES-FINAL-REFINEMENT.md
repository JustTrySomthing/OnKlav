# Games final refinement

Cats vs Dogs now places its23px turn caption and30px animated event headline at the midpoint between the scoreboard and the actual grid top. Feedback uses unboxed outlined/shadowed lettering, a damped pop and radial sparks. Existing drop/bounce, win-line/confetti, AI, journals and friend rules are preserved. Reduced motion suppresses the additional scale/sparks.

Crash Test Panda restores the original gold/cream CannonArt design in Godot, its partly exposed loaded face, a tall left charge meter and bottom-anchored right reserve. Exactly one head arcs into the barrel over900ms; aiming/countdown wait for arrival. The launcher sits lower. Bottom Rocket/Heavy/Shockwave/Launch buttons and tiny helper text are removed. Drag/pull/release remains the launch gesture. Reset and Random are light grey, left/right of the green Ready action. The30-second build countdown fills and submits a legal layout on expiry. Reports/loading/delivery/Pause do not charge input time. The central timer is larger and displayed for both build and aim. Level/round text has larger high-contrast outlined lettering. Results are unboxed, with animated type/sparks and existing bounded particles.

New campaigns use8/10/12 larger mixed blocks across the three existing environments and differing platform layouts. Toppled blocks earn100 points. Occasionally a golden duck crosses the flight area; an actual projectile collision awards250 points once per attack. Later odd rounds include a star block: toppling it during its illuminated pulse awards150 points and a radial impulse; on the hardest level it also grants one extra panda, capped at four total shots. These bonuses are deterministic model state, saved with the flight, bounded and replayed identically by peers. Campaign winner compares actual points, then round/level wins. Paired-round comparisons still compare blocks/shots/power. This is a balance refinement, not a claim of external commercial certification.

New friend invitations usept2, with revision2 explicitly passed through native launch metadata. Existingpt1 invitations/games remain accepted and initialize revision1. Old solo and in-flight saves retain their original six-to-eleven-block dimensions, physics, points and schema1 behavior. The decoder normalizes JSON numeric revisions and validates bonus state. Both phones need this host update for a newpt2 match; an older host cannot silently run the new rules.

Shared audio now tapers generated note and toolbar-cue boundaries to zero, caches Panda's synthesized point/bonus/win sounds before gameplay, keeps swept-oscillator phase continuous, adds a Master limiter and uses a100ms streaming buffer for scheduling headroom. These address click/clipping and avoidable scheduling-stall risks. Existing tracks/effects, buses, mute/music controls and pause behavior are retained. Actual static, audio latency and OEM playback quality still need confirmation on the owner's phone; browser/source checks do not certify audible handset output.

Games catalog cards share one height, scaled together for large system text. A persistent right-hand scrollbar has drag-to-scroll and accessible scroll actions. Tapping the current game resumes that identity. Tapping a different game shows the named active game/invitation and requires an explicit choice to open it; it never silently substitutes the paused game. Host launch claims are serialized through GameSessionStatus; only the owning game may release its marker. Web callbacks use their launched session identity and closing callbacks are ignored. Failed launches cannot erase another game's marker.
