# Game controls v2 / source0.100.45 code154 / SDK0.3

Pause/Play is now a direct silent toggle with the matching icon. Sound/Settings pause silently and Done resumes gameplay directly; no pause menu is created underneath. Quit uses exactly one question and a horizontal green Resume/red Quit row. Header Return and Android Back silently checkpoint/pause. Reopening offers New left and Resume right; New opens a menu of implemented modes and does not replace the previous save until a mode is selected. Single-player-only games do not offer a fake friend option.

These behaviors live in the canonical GameChrome and OnKlavGame helpers, which are used by the bundled games and all SDK templates. The complete author contract, exact dialog text/colors/layout, real-mode callback API, snapshots, reserved mode key, upgrade and recovery requirements are in developer/games/GAME-CONTROLS.md. README/FORMAT/PERFORMANCE were refreshed to remove conflicting current instructions. SDK0.3 requires host154 and controls v2; the shared engine binary is reused.

The Android activity tracks the current game, including after process recreation, and presents the shared in-game New/Resume flow when a different game is clicked. Resume retains the current game; New opens the requested game's start menu. Exit clears the current-game pointer; failed/missing games clear stale pointers so the catalog is not trapped. All game-origin actions remain scoped to the current activity.
