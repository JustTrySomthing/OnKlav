# Write toolbar, save choices and English proofreading

Document name moves from the toolbar to a tappable, ellipsized footer label. Word count remains alongside; character count is available in Settings and accessibility text. The normal Saved status is removed, while errors remain visible. Formatting and auxiliary controls wrap instead of scrolling sideways. Existing image/link/list/font/paragraph/find/replace/export capabilities remain.

Save icon opens a heading-free dialog with full-width Save (Overwrite) and gray Close (Discard Changes), followed by wrapping DOCX/PDF/HTML/TXT/Write export choices, descriptions and a format-specific export action. All export pickers retain OnKlav Files. Autosave protects the draft; explicit Save advances an in-memory checkpoint. Discard waits for earlier disk work, restores the opening/last-explicit-save checkpoint through the normal authorized storage/migration broker, clears history and exits through normal app Back. A recovered autosaved draft becomes the checkpoint when reopened. Exporting a copy does not advance this checkpoint. No saved document is deleted by Discard.

Bundled English (US) SCOWL/Hunspell dictionary expands 163,006 word forms from Debian hunspell-en-us 1:2020.12.07-2. No Android spell-check service or network is required. `scripts/build_write_dictionary.py` records input/output hashes and deterministic gzip output; Android asset packaging expands the .gz file to write/english.txt, which the runtime reads; original notices are bundled and accessible in Settings. Word forms support spelling, not dictionary definitions. Affixes are expanded at build time; no Hunspell native/JVM runtime is added. Suggestions use a common-misspelling table and bounded single-edit candidates. Nosuggest terms are accepted but never proposed. Proper names/unlisted vocabulary can be ignored for the current open document.

Delayed live checks add nonpersistent Android SuggestionSpans. Review lists require explicit replacement and guard stale text. English rules cover repeated words, sentence/I capitalization, common subject/verb agreement, modal-have, a/an, and punctuation spacing. URLs, email addresses, inline code, identifiers and numeric fragments are excluded. These are common-rule checks, not semantic or exhaustive grammar analysis. Up to100 issues appear at a time; applying corrections rechecks remaining text. Settings explains scope, source/license, live-underline toggle and save behavior. Documents are never rewritten automatically.
