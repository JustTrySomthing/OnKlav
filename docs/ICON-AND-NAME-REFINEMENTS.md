# Small-icon readability and shorter app labels

Vault now uses one safe outline, a simple dial and handle, with no feet, hinges or nested door frames. Voice Record keeps the existing handheld microphone without the hanging cord. Files/folder rows, map bookmark folders and New folder use a consistent transparent folder outline. Docu View removes text strokes and separates the lens from the page. Convert has clear vertical gaps between its arrows and ruler. Format Swap removes document interior details and separates both curved arrows from their documents. Compress removes both outer rails, retains vertical inward arrows and widens the center bar.

Included host app display labels are Video Edit, Audio Edit, Image Edit, Voice Record and Screen Record. Catalog/desktop, app manager review/remove/export dialogs, storage headings, app-frame titles, native editor help/error text and recorder/notification titles use the shorter labels. A small host display-name mapping bridges existing signed SDK manifest names; raw signed metadata, packages, publishers, IDs, native request owners and saved data are unchanged. Frame aliases replace only exact old app titles, preserving document titles and menu-specific titles. Recorder destination folder names remain unchanged to keep existing recordings discoverable.

Nine native vector resources were parsed; eight unique designs were rendered from their actual XML paths at36px and24px in light/dark palettes and visually inspected. Stroke bounds fit the32x32 viewports. Catalog IDs, recorder roots/folders and core/JNI/signed SDK bytes were checked against the previous checkpoint. Existing UI name expectations were updated; native SDK metadata assertions intentionally retain original signed names. No new tests, Android compilation, runtime phone verification or APK was performed for these presentation changes. The latest APK0.100.28-rc1 predates both Vault recovery and these refinements.
