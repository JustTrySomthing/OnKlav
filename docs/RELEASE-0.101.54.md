# OnKlav 0.101.54-rc1

The updates dialog now has consistent margins around its text, switches,
progress and buttons, aligned with the dialog heading. Content remains
scrollable on smaller screens and with larger text.

All update checking, download verification and installation behavior from
0.101.53 is retained. Install through Settings → Check for updates, or download
the APK directly. There is no need to uninstall OnKlav.
