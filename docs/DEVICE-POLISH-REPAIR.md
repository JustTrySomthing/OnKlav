Source complete;14unique focused Android checks and full lint with zero errors passed. See device-polish-verification.json. Latest delivered APK0.100.9-rc1/code118 predates this source update and the earlier Audio Editor/crop fix, which are preserved.

Video: the supplied screenshot reports ERROR_CODE_FAILED_RUNTIME_CHECK, without a stack trace or source clip. It is not enough to identify the exact device/codec failure. The old CompositionPlayer handler attempted a compatibility render only for a frame-processing error, then left the automatic-preparing label on a failed source view. Runtime-check/decoder failures now take the bounded existing SDR H264/AAC compatibility render path; its successful file is cached for that project revision and explicit retries reuse it. Device-required shutter sound is respected. Gboard/provider and actual MMS carrier acceptance remain phone gates.
