# OnKlav 0.101.53-rc1

OnKlav can now find, download and install its updates directly from GitHub.

- Open Settings → Check for updates to check manually and download/install a
  newer release, with progress and cancellation.
- Automatic checks run once a day when OnKlav opens and is online. They can be
  switched off. Downloads start only when you choose.
- The updater checks download integrity, the app's existing signing certificate,
  package/version compatibility and Android requirements before handing the
  update to Android's installer for your confirmation.
- Release candidates are supported and can be included or excluded in Settings.
- All carrier connection and game recovery repairs from 0.101.52 are retained.

Install this version manually once to add the updater. Future compatible
releases can then be installed from inside OnKlav. Existing data is retained;
there is no need to uninstall OnKlav.
