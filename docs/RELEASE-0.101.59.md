# OnKlav 0.101.59-rc1

- Sent texts appear in the open conversation as soon as they’re queued. Incoming texts and MMS attachments refresh in both Messages and Groups.
- New-message notifications open the correct conversation and scroll to the message. Hidden conversations leave new messages unread.
- Share, open, and save contact cards (.vcf) in Messages. Choose **Contact card (.vcf)** from the paperclip menu to attach a card from OnKlav Files.
- Each tap on **Check now** checks GitHub again and shows when the check completes.

To update, open **Settings → Check for updates** with **Include release candidates** enabled, or install the signed APK below.
