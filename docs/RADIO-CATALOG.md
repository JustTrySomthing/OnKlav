# Unified Radio directory — 0.85 source update

Radio Browser and Icecast's official machine-readable directory are merged into the existing Stations tab. There are no separate provider tabs. The default All category browses the entire compatible catalog alphabetically; name/tag search, genre, country and language filters apply to the combined data. Unknown country/language metadata is not invented. Pagination is20rows per page and is no longer restricted to the first1,000matches.

The bundled starter catalog contains Radio Browser records from scripts/import_radio_catalog.py. The Radio Browser API permits mirroring its data (https://api.radio-browser.info/). Icecast entries are fetched during live catalog refresh. Their separate redistribution terms are pending. It enables browsing without waiting for a full network export. The host opens its last saved catalog immediately and Settings > Refresh stations requests a refresh (network attempts are limited to once per30minutes). A failing provider retains its previous rows rather than erasing the list. Active paged searches retain their snapshot to prevent refreshing data from moving stations between pages. Raw provider exports are not bundled; only bounded compatible station metadata is included.

Duplicates merge by normalized stream address, or distinctive station identity supported by country/origin/homepage metadata. Alternate codec/bitrate suffixes are normalized. Unambiguous cross-source names can match when Icecast lacks country data; ambiguous/generic names and known different countries stay separate. Transitive duplicate groups preserve all source IDs for playback, and visible rows preserve bookmark aliases. No algorithm can identify unrelated stream URLs as the same broadcaster when providers supply no reliable identifying metadata; ambiguous matches are deliberately kept distinct.

Existing Radio Browser IDs and opaque stream authorization remain supported. Icecast IDs are deterministic namespaced UUIDs. Host-owned metadata for returned stations is retained for saved-station playback after catalog refreshes; provider URLs never enter guest UI/state. Public HTTP/HTTPS MP3, AAC, OGG/Vorbis, Opus, FLAC and HLS are accepted. PLS/M3U listings resolve through bounded host validation. Missing addresses, private targets and unsupported schemes/codecs are excluded. Every playback redirect retains the existing public-address checks, live permissions and owner-bound stream handle.

Public exports are streamed with bounded JSON/XML readers, compressed over HTTP when supported, and cached as compact gzip metadata. XML DTDs, excessive nesting, oversized documents and excessive station counts are rejected. Public catalog parsing checks cancellation continuously, throttles repeated native grant checks during bulk parsing, and reauthorizes before returning rows. Existing private favorites and recent history remain in their original collections.

No APK was requested or produced for this source update. The next APK must contain the new host, native bridge, signed Radio package and catalog asset. Preserve the released0.84APK and original signing identities. Physical-phone playback/latency and provider uptime are separate from host checks.
