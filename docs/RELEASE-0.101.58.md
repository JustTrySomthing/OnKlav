# OnKlav 0.101.58-rc1

- The update dialog shows the available version once and keeps **Update now**
  visible without scrolling. The file size is hidden.
- With **Check daily** enabled, OnKlav checks on the first online launch after
  a phone restart, even if it checked earlier that day.
- **Last checked** shows when the most recent check completed.

From an earlier release candidate, open **Settings → Check for updates** with
**Include release candidates** enabled, or install the signed APK below.
