# OnKlav 0.101.50-rc1

This corrective Android prerelease restores saved development updates omitted from
the 0.101.49-rc1 reconstruction. It increments the Android version code from 228
to 229 and uses the existing package and Android signing identity.

- Restores the clean-install desktop order, responsive layouts, Files storage
  tabs and cross-storage transfers, and updated phone and in-call keypads.
- Restores GMX setup, browser-backed cloud account setup, the Walkie-Talkie panel,
  eBook reader fixes, and the Video Edit launch and layout updates.
- Restores game layout and touch changes, including Naval Battle, Cats vs Dogs,
  Air Hockey, Blackjack, Crash Test Panda, Last Light Express, and Shroom.
  Air Hockey keeps backward-compatible difficulty saves.

The bundled shared Godot pack and the Last Light Express and Shroom cartridges
are rebuilt from this source. Music Maker remains retired. Existing desktop
arrangements are preserved.
