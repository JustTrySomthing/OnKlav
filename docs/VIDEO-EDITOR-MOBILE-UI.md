# Video Editor mobile workspace refinement

Four labelled groups replace the13-button horizontal dock: Edit (Edit/Transform/Speed/Keyframes), Audio, Layers (Text/Captions/Overlay), Finish (Filters/Transitions/Fades/Canvas). The selected category remembers its tool. A wide labelled menu selects tools; preview/proxy settings and guide are in More. No editing feature was removed. Export remains in the header with an accessible labelled icon.

The workspace uses actual remaining bounds. Portrait reserves a preview and persistent playback/history row, then provides a bounded, separately scrolling inspector with a scroll indicator. On short or large-text phones the inspector takes the timeline's place; Done or Android Back returns to it. Wide landscape places preview/playback/timeline on the left and tools on the right. Timeline controls combine selected-clip context, zoom, Split and Add; duplicate/delete remain in Edit (and layer controls). Overlays/captions/audio timeline lanes are44dp rather than25dp, with vertical scrolling.

Touch actions/reset controls/sliders are48dp; switches have56dp full-row targets. Inspector actions wrap instead of running off screen. Audio has a source selector (Clip audio or one imported track) and Add audio/Voiceover/Extract action tiles, rather than a stack of all four tracks. Tool changes reset inspector scroll; pinching/dragging the preview and timeline editing remain. Fullscreen shows a source frame and clear Play/retry hint while an edited preview is unavailable. Status text stays compact with selectable full details. Title/caption settings use one scrolling form rather than nested fixed-height scrolling.

Five focused screen checks passed using exact production UI/data/contracts/resources in a temporary Android/Compose module with explicit test-only model, permission, PlayerView and composition placeholders. They verify layout/control callbacks, not the real media engine. Small portrait, short portrait,160% text, landscape, fullscreen/error details were inspected;5 PNG captures are retained. Compiled/runtime class bytes match. The full-app test navigation was updated, but not executed because its current Camera/Mail/Media3 dependencies were not restored. No phone/IME/playback/export/codec qualification and no new APK. Existing Audio Editor and incoming-message changes are retained.

Reproduce the isolated checks with scripts/check_video_mobile_layout.py and a restored build environment.
