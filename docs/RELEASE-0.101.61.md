# OnKlav 0.101.61-rc1

- Email setup now handles Android’s private storage paths correctly for GMX, Google, Yahoo, and Private domain. This fixes a local “Check failed” error that could occur before a mail server was contacted.
- Google app passwords can be pasted with spaces.
- An existing email account can update its outgoing password while keeping its saved incoming password.

To update, open **Settings → Check for updates** with **Include release candidates** enabled, or install the signed APK below.
