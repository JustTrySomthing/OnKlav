# Cats vs Dogs artwork

Original artwork created for Inner Circle with OpenAI image generation, October 2026. No third-party character or brand references.

- cat.webp: transparent circular wine-and-rose token with a dark silhouette outline, cute orange tabby, green eyes, contained face and ears, generous clear edge.
- dog.webp: matching transparent circular cobalt-blue token, cute golden retriever puppy, happy tongue, contained face and ears.
- catalog.webp: cat and dog portraits as a transparent cutout.

Version 2.2.15 resizes the bundled art to 384px for its actual display size, using WebP encoding at that resolution. Runtime decodes each once off the UI thread. Gameplay retains the exact seven-column, six-row board and existing rules/AI. The catalog is illustrative.

The in-game coins now show front-facing versions of the catalog's orange tabby with red neckerchief and brown dog with blue collar and gold buckle. Both use the same circular treatment and preserve the wine-red versus cobalt team contrast.
